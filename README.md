## Description

Start with one planet and build it into a galactic empire. Tap to bootstrap, then automate production, research new tech, send fleets to conquer neighbouring worlds and watch short fleet-clash cinematics play out. A Command Doctrine tree unlocks as your empire grows, so the game keeps changing well past the first session.

## Key features

- Build and upgrade structures to automate resource production
- Research tech that compounds as your empire expands
- Raise fleets and conquer planets across the star map
- Fleet-clash battle cinematics on every conquest
- Command Doctrines: a three-branch progression tree funded by conquest
- Bright, family-friendly cosmic art style
- Available in 10 languages
